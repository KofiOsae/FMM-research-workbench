# FMM Research Workbench

A local browser interface for periodic photonic structures. Seven workspaces separate scattering and fields, planar guided modes, 2D band structure, measured-data fitting, cavity estimates, materials, and tutorials. A transfer-matrix calculation provides an independent uniform-stack check on the finite-slab FMM solver. The workbench was developed after reviewing the 2018 `ThetaSpektri.py` script and the two MATLAB projects in `PWEM_RCWA_Issah`.

> **Research preview:** results require case-specific convergence, material-provenance checks, and comparison with an analytic result, independent solver, experiment, or literature benchmark before they support a scientific claim.

Development was substantially assisted by **ChatGPT Codex by OpenAI**. See [AI_ASSISTANCE.md](AI_ASSISTANCE.md) for the acknowledgement and responsibility statement.

## Start

On Windows with Python 3.12 installed, double-click `start_windows.bat`. It starts the solver in the background, verifies its health, and opens **http://127.0.0.1:8765/**. Closing the launch window no longer stops the solver. Use `stop_windows.bat` when you want to stop it. The first launch creates a virtual environment and installs pinned packages. Alternatively:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

The server binds to `127.0.0.1`; it is local to this computer. Run checks with:

```powershell
.\.venv\Scripts\python.exe -m unittest -v
.\.venv\Scripts\python.exe benchmark_mpb.py
```

See [VALIDATION.md](VALIDATION.md) for the independent physics checks and their limits, and [DEPLOYMENT.md](DEPLOYMENT.md) for the work required before public hosting.

## Contributing and citation

Bug reports, validation cases, documentation corrections, and focused solver improvements are welcome. Read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting a pull request. Use the software citation generated by GitHub from [CITATION.cff](CITATION.cff), cite the underlying solver and material datasets used in a result, and preserve the exported methods report with research outputs.

The workspace tabs keep each physical problem separate. **Scattering & fields** contains finite-stack FMM, a schematic 3D preview, spectra, convergence, fields, and a uniform-stack transfer-matrix comparison. **Guided modes** contains the planar eigenmode workflow. **Band structure** contains the infinite-crystal workflow. **Measurements & fit** compares uploaded spectra with simulation, retains the original single-thickness teaching fit, and adds bounded multi-parameter TMM/FMM fitting with covariance, correlations, validation wavelengths, identifiability checks, global initialization, and residual bootstrap. **Sweeps & design** evaluates one- or two-parameter FMM design spaces and checkpointed resonance-Q studies with pause, continue, cancel, export, and automatic best-point validation. **Cavity estimate** evaluates the ideal single-mode Q/V expression and structure-specific planar electric-dipole LDOS above uniform multilayers at one wavelength or across a wavelength sweep. **Materials** documents and imports optical constants. **Tutorial** explains setup, interpretation, validation status, and references. In the transfer-matrix card, choose a uniform stack and run either a single-wavelength FMM comparison or a transfer-matrix spectrum; patterned layers are rejected because a one-dimensional film model has no diffraction.

## Choosing a calculation

| Workflow | Physical model | Supported inputs | Main outputs |
| --- | --- | --- | --- |
| Spectrum | Finite stack of layers, periodic in x and y | 1–64 layers; uniform films, 1D ridges or slots, rectangular/circular pillars or holes, ellipses, and rings; constant or catalog/imported optical constants; s, p, or unpolarized illumination from either side | Total R, T, A=1−R−T and zero-order R/T |
| Single wavelength | Same finite stack | One vacuum wavelength and incidence direction | R/T/A, diffraction orders, Fourier-order and geometry-grid checks |
| Angle–wavelength map | Same finite stack scanned over incidence angle and vacuum wavelength at fixed azimuth | 3–41 points per axis; s, p, or unpolarized; R/T/A or zero-order R₀/T₀ | Color map with center-point Fourier check and skipped-cutoff reporting |
| Incident k-space map | Same finite stack scanned over transverse incident wavevector at one wavelength | Odd 5–41 point grid inside k∥/(nᵢk₀)=sinθ | R/T/A or R₀/T₀ over kx,ky with explicit polarization convention |
| Field map | Same finite stack | One patterned layer and depth within it | Horizontal x–y map of relative electric intensity and real Ex/Ey/Ez; refinement checks |
| Transfer matrix | Laterally uniform finite stack; independent scattering recursion | 1–8 uniform layers, absorbing or lossless, s/p/unpolarized, oblique incidence | Specular R/T/A spectrum and direct single-wavelength FMM comparison |
| Band structure | Infinite, z-invariant, lossless 2D crystal | Square, rectangular, or triangular/hexagonal Bravais lattice; one disk, square, or ring in a constant-index background | TE (Hz) and TM (Ez) frequencies on the standard high-symmetry path, with Fourier-order comparison |
| Planar waveguide | Separate three-medium, lossless, uniform dielectric core and two semi-infinite claddings | Core and cladding materials, core thickness, wavelength, TE/TM mode | Bound-mode effective index, propagation constant, approximate group index, transverse profile and confinement estimate |
| Measurement fit | Uploaded wavelength and R/T/A data compared with a uniform multilayer model | CSV data and one selected layer with bounded thickness | Overlaid curves, residuals, RMSE, and best-fit thickness |
| Cavity estimate | Ideal single-mode weak-coupling Purcell equation | Q, mode volume, wavelength, refractive index, detuning, and emitter linewidth | Ideal and detuning-adjusted enhancement estimates |

All lengths are in **micrometres**. Angles are in degrees. The frequency axis of a band diagram is **a/λ**, where `a` is the first primitive-vector length. Layers are always listed physically from top to bottom; the illumination control chooses which side is incident. A feature's dimensions are fractions of the unit-cell axes. Disk and ring radii are fractions of the period. A stripe extends across the complete unit cell in y and repeats in x, making a 1D grating. Square, rectangular, and oblique 60° triangular/hexagonal Bravais cells are available. “Triangular” and “hexagonal” here name the same Bravais lattice; the feature control selects the motif. Unpolarized R/T/A is the incoherent arithmetic mean of separate s and p runs; field maps require a chosen polarization.

For finite-slab RCWA, the illumination travels from the **incident medium through layer 1 and subsequent layers to the exit medium**. At normal incidence it points along +z. The polar angle θ is measured from that normal and azimuth φ from +x in the layer plane. To calculate illumination from the other face, reverse the layer order and swap the incident and exit refractive indices. This finite-slab model describes external plane-wave illumination; it does not automatically solve waveguide eigenmodes or launch light along a waveguide.

The **Planar waveguide modes** card is a separate 1D eigenmode calculation. Here the core fills 0 < z < thickness, with semi-infinite upper and lower claddings; light propagates along +x. It solves the TE electric or TM magnetic scalar slab dispersion condition, including the correct TM permittivity boundary factors. `n_eff = β/k₀` identifies the phase propagation constant. The transverse plot shows normalized |Eᵧ|² for TE or |Hᵧ|² for TM. The core fraction integrates the along-waveguide Poynting flux: |Eᵧ|² for TE, and |Hᵧ|²/ε for TM in these nonmagnetic media. It is not a coupling efficiency. The displayed group index is a central finite difference of `n_eff(λ)` and may be unavailable near cutoff; the interface reports the change when halving its wavelength step. This solver currently requires a uniform isotropic **lossless** core with a larger index than both claddings; it does not find lossy, leaky, laterally confined, or periodically patterned waveguide modes. Launching a guided mode into a patterned stack and measuring modal transmission is a separate calculation not yet provided.

The **Unpatterned slab-mode phase matching** assistant links this bound-mode model to a periodic stack through `β ≈ |k_parallel + m b1 + n b2|`. A selected uniform layer is used exactly; a patterned layer is replaced by the arithmetic unit-cell mean of ε and this homogenization is reported. The assistant evaluates reciprocal vectors for square, rectangular, and oblique cells and ranks integer `(m,n)` orders by relative momentum mismatch. This establishes momentum compatibility only. Patterning can shift the mode and controls overlap, radiation loss, linewidth, and coupling strength, so the actual resonance must be verified with FMM spectra, fields, angular or period dispersion, and convergence.

The gold table is Johnson and Christy's measured bulk `n,k`, interpolated separately without extrapolation. The supported range is 0.1879–1.9370 µm. Fused silica uses Malitson's Sellmeier formula over 0.21–6.7 µm. N-BK7 optical glass uses the SCHOTT Sellmeier formula over 0.3–2.5 µm. Calcium fluoride uses Malitson's Sellmeier formula over 0.23–9.7 µm. Crystalline silicon uses the Green 2008 tabulated `n,k` at 300 K within its tabulated wavelength range. The library also contains ordinary-ray dispersion for rutile TiO₂ (DeVore, 0.43–1.53 µm), synthetic sapphire α-Al₂O₃ (Malitson–Dodge, 0.20–5.0 µm), and MgF₂ (Dodge, 0.20–7.0 µm). Formula models return real n and do not represent absorption near transparency edges. Constant-index dielectrics are idealizations, not a measured dispersion model.

The Materials workspace includes a separate constitutive calculator for a rotated uniaxial permittivity tensor, scalar relative permeability, thermo-optic and Kerr index shifts, and small-signal gain. It solves the exact homogeneous plane-wave Maxwell eigenproblem and reports the two bulk indices and polarizations. This is material preprocessing and validation: tensor ε/μ, heat diffusion, nonlinear self-consistency, and gain saturation are not yet coupled to the layered FMM, band, or waveguide matrices.

## Validation and how to interpret the badges

The 56 automated tests check measured-material reference values and range limits, analytic Fresnel reflectance at normal and oblique incidence for both polarizations, complex diffraction-order fields, linear-polarization Stokes limits, coherent far-field k-space maps, slab/grating phase matching, an independent Fabry–Pérot formula for a uniform N-BK7 film, power balance and layer-resolved absorption for dielectric and absorbing structures, square/rectangular/hexagonal band calculations, the analytic folded bands of a uniform 2D medium, measurement fitting, the Q/V cavity expression, the Ag/TDBC–PVA two-branch strong-coupling benchmark, and a published MPB square-rod benchmark. The guided-mode tests compare both polarizations against independent symmetric half-slab dispersion equations and check mode bounds, cutoff, fields, and figures. In the MPB case (rod ε=12, r/a=0.2, k=(0.3,0.3)), this plane-wave code gives first TE frequency **0.37555** at Fourier order 7, compared with **0.372604** in the MPB tutorial. The difference is 0.00295 in normalized frequency (0.79%). That is a useful independent check, **not** a universal accuracy bound.

Every quantitative plot has a **Raw data + metadata** action. Line plots export the sampled series; two-dimensional maps export both coordinate arrays and the unsmoothed calculated matrix. The JSON also records the current model, plot identity, palette, smoothing selection, timestamp, and a reminder that display interpolation does not change the numerical samples.

The interface marks a single-wavelength result as passing only if changes in R, T, and A across 29 and 57 retained Fourier orders are each at most 0.01, the grid-size doubling changes them by at most 0.01, and the power balance remains physical. A spectrum compares orders point by point, but does **not** double the geometry grid at every wavelength; select important wavelengths for the full check. A field map compares its intensity pattern across Fourier and grid refinements using a relative RMS threshold of 0.10. Band diagrams compare each displayed band between adjacent Fourier orders with a 0.01 normalized-frequency threshold.

These thresholds are screening criteria, not proof of experimental accuracy. Near a resonance, at a Rayleigh cutoff, or at a sharp metal boundary, convergence may be slow. Results that fail are shown for diagnosis but figure export is disabled. The legacy gold-rectangle preset near 0.9 µm **fails** Fourier convergence and must not be used as a quantitative result. The solver rejects exact grazing-order cutoffs where its matrices become singular.

The R/T/A values include all propagating orders retained by the solver. Global absorptance is the residual `1−R−T`. The vertical-field workspace computes each layer's absorption from the decrease in Fourier-domain unit-cell-averaged normal Poynting flux and checks its sum against global absorptance. It independently integrates `normalization × ω Im(ε)|E|²` over the complete sampled unit cell and layer thickness and reports both values. Their difference is a spatial-integration convergence diagnostic. Horizontal and vertical field maps are relative to the solver's unit incident-wave convention, not calibrated experimental intensity. The weak-loss Brillouin energy estimate uses `¼{[ε′−λ dε′/dλ]|E|²+|H|²}` and is marked unsuitable when any selected material has `k/n > 0.01` or a nonpositive derivative coefficient. The original nondispersive proxy remains available for comparison.

Single-wavelength coherent s or p results include the complex Cartesian E and H coefficients of every propagating reflected and transmitted diffraction order. The interface shows the dominant tangential electric component, magnitude, and phase. It also projects each outgoing channel onto its local p/s basis and reports complex Jones coefficients, normalized Stokes parameters, polarization orientation, and ellipticity. The convention is `S3 = −2 Im(Ep Es*)`; exported JSON retains all components. Phases use the incident-wave reference and depend on the selected port/reference-plane convention. Unpolarized light is an incoherent s/p average and therefore has no single coherent order phase or Jones vector.

The Jones and Stokes k-space workspace repeats that coherent channel calculation over incident `kx,ky`. It can map channel power, normalized complex `Ep,Es`, normalized Stokes parameters, orientation, and ellipticity for a selected reflected or transmitted diffraction order. Values below a user-selected power threshold are masked because normalized polarization is unstable as `S0→0`. Every pixel is a driven scattering result and includes any direct background. It is not the isolated radiation coefficient of a leaky eigenmode. A BIC charge requires the winding of the isolated mode radiation polarization around a closed momentum-space loop, together with mode tracking and convergence; the present workspace intentionally does not assign that charge.
The field viewer also allows real Ex, Ey, and Ez components. Their signed patterns depend on the chosen incident phase reference, so use |E|² for phase-independent enhancement comparisons. The field figure export follows the selected quantity and labels its color scale.

In the slab solver, the Fourier input is a requested total number of harmonics. The solver chooses and reports the actual retained count, which need not equal the request; the input itself need not be odd. In the band solver, the input `N` is a radius and the basis contains orders `−N…+N`, or `2N+1` along each reciprocal axis. The single-wavelength result plots R/T/A against actual retained harmonics and also shows the largest order and grid changes against a dashed acceptance limit. Passing this numerical screen does not replace an independent comparison for the specific sample.

## If the app gives an error

Read the message above the plot first. Material range errors mean the selected wavelength falls outside the cited optical-constant data; choose an in-range wavelength or a justified custom index. A grazing-cutoff message means a diffraction order is exactly at threshold; move the wavelength or angle slightly. Invalid geometry messages identify a fraction, radius, layer count, grid size, or index to correct. A failed convergence check is a calculated but unresolved result: inspect the convergence chart, raise Fourier harmonics and grid resolution within limits, and avoid quoting the unstable value. For an unexpected server error, inspect `workbench.log` in this folder for a traceback, run the unit tests from the Start section, and keep the input settings and error message for reproduction. The browser's developer console can reveal JavaScript errors if a control does not respond.

## Relation to the MATLAB files

- `PWEM_RCWA_Issah/BAND_structures-master/PWEM_imp.m` motivated the ring/disk/square geometry and Γ–X–M–Γ path. This workbench uses a fresh Hermitian generalized eigenproblem for TM Ez and TE Hz. The MATLAB file's TE/TM names do not match the standard MPB convention used here.
- `PWEM_RCWA_Issah/PWEM-TMM_fields-master/RCW_FMM.m` motivated the four-layer dielectric-ring preset and the finite-slab field workflow. Its `ya` coordinate uses `dx` rather than `dy` (line 45), the ring radii are pixels rather than explicit lengths (lines 136–147), and its field plot uses only the real part of the field components. The new preset maps those radii to fractions of the period; it is an interpreted example, not a claim of exact reproduction of its output.
- The legacy MATLAB files remain untouched. They are not used as trusted numerical references because several geometry and unit choices are ambiguous. The `PWEM_imp.m` square test compares a length to a squared radius (line 45), and the ring/triangle branches use separate discretization choices. These should be corrected before direct cross-code numerical comparison.

## Reproducibility and publication

Export **JSON** with parameters and results and **CSV** for validated spectra. Export **SVG** for editable vector figures or **PNG** at 300 dpi. Include the optical-constant source, all layer parameters, incidence angle/polarization, Fourier order, spatial grid, convergence changes, and package versions in a methods section. Keep a record of any data-processing or fitting steps performed outside this workbench.

For a publishable conclusion, repeat the calculation with higher orders and grid size, compare against an independent solver or experiment for the specific geometry, and include material-property uncertainty. A slab spectrum peak cannot by itself be identified as an infinite-crystal band edge; the two calculations have different boundary conditions.

## Current research limits

This is a validated **preview**, not a full Lumerical replacement. Gold patches close to the original 2018 scan have not converged at the installed solver's practical order budgets. Near-field maps, band edges, resonant features, and any new material or geometry need case-specific convergence and external comparison before they support a research claim. Multi-parameter fitting provides local covariance, correlation, conditional confidence intervals, reserved-wavelength validation, and optional residual bootstrap. The Bayesian workspace adds bounded multi-chain posterior sampling under an explicit independent Gaussian likelihood; its intervals remain conditional on the chosen optical model, priors, bounds, and noise model. Pause and resume operate between completed solves rather than resuming a matrix factorization in progress. Driven k-space Jones/Stokes maps and a stability-checked complex-sideband resonance decomposition are available, but polarization-vortex winding and topological charge still require an isolated patterned-mode pole. Band scalar eigenfields and a frozen-index normal-incidence complex-pole solver for uniform multilayers are available. A dyadic Green-function solver gives planar electric-dipole LDOS and rigorous upper-medium objective-cone collection for uniform multilayers, including orientation and numerical refinement. It does not provide a beta factor into a named mode. Patterned-source LDOS, patterned RCWA poles, normalized quasinormal fields, and self-consistent thermal/nonlinear/gain/tensor stack simulations remain future solver subsystems. A full-vector finite-difference mode workspace is available for rectangular 2D dielectric waveguide cross sections and returns all six complex field components; mesh and boundary convergence remain mandatory.





## Resonance and angular workflows

- Spectrum plots show R, T, A, and the energy-accounting sum R+T+A. Hover to inspect sampled values; click a wavelength to send it to Single wavelength and Field map.
- Two-dimensional maps offer sampled-cell, linear, and high-quality smooth rendering after a solve. Interpolation is visual only; hover reports the nearest solved sample.
- Signed angle maps use negative theta as the reversed in-plane wavevector (phi + 180 degrees), enabling symmetry comparisons about normal incidence.
- Adaptive resonance analysis refines a wavelength interval and fits a Fano profile, with a Lorentzian fallback for symmetric features. Reported linewidth, Q, and covariance errors remain far-field fit estimates. They do not prove an ideal BIC.
- The adaptive workspace retains its single-feature workflow and now also offers a multi-feature workflow. The latter performs a global candidate scan, candidate-wise refinement, joint shared-background Lorentzian/Fano fitting, BIC model comparison, covariance and overlap warnings, and field-signature-assisted branch assignment. These remain phenomenological far-field fits rather than complex-frequency poles or QNMs.
- Geometry primitives include 1D ridges and slots, rectangular and circular pillars or holes, ellipses, disks, rings, and uniform films. The stack supports up to 64 finite layers.


## Added research workflows

- Complete-stack lossless planar TE/TM modes after lateral homogenization, with vertical profiles and analytic slab validation.
- Automatic slab phase-matching dispersion compared with the actual FMM reflection spectrum.
- Resonance-aware vertical fields at the center, half-linewidth points, and an off-resonance wavelength.
- Seeded fabrication-tolerance Monte Carlo studies with percentiles and local sensitivity screening.

- Measured-spectrum nuisance fitting for wavelength offset, intensity scale, background, and Gaussian instrument bandwidth.
- Complex sideband Jones/Stokes subtraction with a sideband-spacing stability check.
- Normal-incidence complex poles for uniform multilayer stacks, with frozen optical indices and a loss-removed radiative-Q estimate.

## Visualization conventions

Quantitative line plots use labeled axes, units, legends, sampled-point markers, and hover readouts. Two-dimensional maps use numeric colorbars and hover readouts of the nearest calculated sample. Horizontal field plots overlay the selected feature boundary; vertical fields and resonance-field comparisons overlay layer interfaces; band eigenfields overlay material boundaries; planar mode profiles overlay physical layer boundaries. The global display selector can smooth raster presentation, but exported interpretation must treat smoothing as visual interpolation rather than additional simulation data.


## Expanded optical materials

The library now includes Rakic Lorentz–Drude Ag, Al, and Cu over 0.1–6 eV; measured PMMA, polycarbonate, polystyrene, and Zeonex E48R values over 0.4368–1.052 µm; and a measured-film SiN Sellmeier fit over the explicitly limited interface range. These models are process dependent. Thin metal films, deposited SiN, and commercial polymers can differ from the cited specimens, so sample-specific ellipsometry should be imported for quantitative device fitting. Field JSON now includes real E and H components and time-averaged Poynting components used by the normalized arrow overlays.

## Closed-loop polarization winding

The scattering workspace tracks a fitted resonance around a closed momentum-space loop, subtracts a symmetric complex sideband background in fixed laboratory Cartesian coordinates, unwraps the headless polarization-axis angle, and tests stability against loop radius, sideband selection, ellipticity, residual amplitude, branch continuity, and Fourier convergence. Sideband subtraction approximates an isolated pole residue, so rigorous ideal-BIC proof still requires the future patterned outgoing-mode solver.


## General constrained geometry optimization

The Sweeps and design workspace supports one to five bounded model parameters, one to eight weighted optical objectives, optional linear constraints, seeded differential-evolution search, optional local polishing, complete evaluation history, application of the selected geometry, and Fourier/grid validation at every objective wavelength. It is a low-dimensional shape and parameter optimizer rather than a pixel-level adjoint topology optimizer. Repeat stochastic searches with multiple seeds and evaluate tolerance before accepting a design.
