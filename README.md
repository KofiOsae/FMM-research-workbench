# FMM Research Workbench

A local browser interface for periodic photonic structures. Seven workspaces separate scattering and fields, planar guided modes, 2D band structure, measured-data fitting, cavity estimates, materials, and tutorials. A transfer-matrix calculation provides an independent uniform-stack check on the finite-slab FMM solver.

> **Research preview:** results require case-specific convergence, material-provenance checks, and comparison with an analytic result, independent solver, experiment, or literature benchmark before they support a scientific claim.

Development was substantially assisted by **ChatGPT Codex by OpenAI**. See [AI_ASSISTANCE.md](AI_ASSISTANCE.md) for the acknowledgement and responsibility statement.

## First use and the training upgrade

Open [the illustrated first-use handbook](FIRST_STEPS.html), or choose **First steps** from the app toolbar. It includes an external MPB benchmark, analytic controls, exact inputs, expected behavior, interpretation, and warning recovery. [The metasurface and arbitrary-geometry guide](METASURFACE_GUIDE.html) continues from an application target through binary-mask import, unit-cell validation, a local-periodic phase library, flat-lens assignment, and microfiber-knot spectral metrics. Use the browser print command for a PDF copy.

The persistent **Run from here** selector starts workspace operations without scrolling. **Find a tool in this workspace** searches and groups cards as Set up, Analyze, Design, Validate, and Learn; its focus option temporarily hides the other cards so a long specialist workspace can be used without repeated scrolling. **Show all cards** restores the full workspace. The run monitor shows measured elapsed time, completed work where the solver reports checkpoints, and a remaining-time estimate. Matrix solves without checkpoints show indeterminate progress. Runs are queued one at a time, with at most four active/queued jobs; cancellation is cooperative. A durable **Run history** keeps the latest 100 completion summaries across server restarts. Estimates depend on the current machine and settings.

Angle–wavelength and scalar k-space maps allow up to 201 points per axis; polarization maps allow up to 101. Spectra allow up to 2,001 wavelengths. The finite-stack solver accepts a requested Fourier budget up to 201 and a geometry grid up to 512 cells per axis. Grid-doubling validation therefore requires a starting grid no larger than 256. Set **My maximum scan points** to your own smaller limit before running (default 10,000; ceiling 40,401). The vector-mode solver accepts up to 120,000 cells and reports requested cell counts on failure. Higher resolution increases compute time and memory sharply; it does not replace convergence checks.

TMM includes coherent reflection/transmission phase; field components and Jones maps offer phase views, masking undefined values. Intensity, total power, LDOS, and incoherent averages do not have a single optical phase. The vector mode solver supports rectangular, elliptical, and trapezoidal isotropic cores and includes a baseline/half-mesh/larger-padding workflow and comparison history. The band workspace can screen a complete sampled reciprocal primitive cell so a gap is not inferred from the standard symmetry path alone.

The Bayesian workspace reports rank-normalized split R-hat, bulk and tail effective sample size, posterior predictive coverage, and optional AR(1) spectral residual correlation. Geometry optimization can include fixed seeded fabrication perturbations and reports the mean, standard deviation, and worst objective among those samples. These diagnostics remain conditional on the stated model and bounds.

Patterned layers can also use an imported or brush-drawn binary mask. PNG/JPEG/SVG images and numeric CSV matrices are thresholded into background and feature materials, stored directly in project JSON, and resampled onto the selected geometry grid. A complete mask can be rotated in plane, or retained while a rotated and translated periodic copy is merged into the same layer to form compound meta-atoms. These raster transformations should be followed by feature-size inspection and convergence checks. This represents a two-material periodic cross section extruded through one layer; it is not a general finite 3D CAD mesh. The metasurface assistant sweeps one parameter to build a coherent specular phase/power library and exports a radial flat-lens assignment under the local periodic approximation. The exported assignment is not a finite-aperture focusing simulation.

## Start

On Windows with Python 3.12 installed, double-click `start_windows.bat`. It starts the solver in the background, verifies its health, and opens **http://127.0.0.1:8765/**. Closing the launch window no longer stops the solver. Use `stop_windows.bat` when you want to stop it. The first launch creates a virtual environment and installs pinned packages. Alternatively:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

The server binds to `127.0.0.1`; it is local to this computer. Run checks with:

```powershell
.\.venv\Scripts\python.exe -m unittest -v
.\.venv\Scripts\python.exe benchmark_mpb.py
```

See [VALIDATION.md](VALIDATION.md) for the independent physics checks and their limits, and [DEPLOYMENT.md](DEPLOYMENT.md) for the work required before public hosting.

## Contributing and citation

Bug reports, validation cases, documentation corrections, and focused solver improvements are welcome. Read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting a pull request. Use the software citation generated by GitHub from [CITATION.cff](CITATION.cff), cite the underlying solver and material datasets used in a result, and preserve the exported methods report with research outputs.

The workspace tabs keep each physical problem separate. **Scattering & fields** contains finite-stack FMM, a schematic 3D preview, spectra, convergence, fields, and a uniform-stack transfer-matrix comparison. **Guided modes** contains the planar eigenmode workflow. **Band structure** contains the infinite-crystal workflow. **Measurements & fit** compares uploaded spectra with simulation, retains the original single-thickness teaching fit, and adds bounded multi-parameter TMM/FMM fitting with covariance, correlations, validation wavelengths, identifiability checks, global initialization, and residual bootstrap. **Sweeps & design** evaluates one- or two-parameter FMM design spaces and checkpointed resonance-Q studies with pause, continue, cancel, export, and automatic best-point validation. **Cavity estimate** evaluates the ideal single-mode Q/V expression and structure-specific planar electric-dipole LDOS above uniform multilayers at one wavelength or across a wavelength sweep. **Materials** documents and imports optical constants. **Tutorial** explains setup, interpretation, validation status, and references. In the transfer-matrix card, choose a uniform stack and run either a single-wavelength FMM comparison or a transfer-matrix spectrum; patterned layers are rejected because a one-dimensional film model has no diffraction.

## Choosing a calculation

| Workflow | Physical model | Supported inputs | Main outputs |
| --- | --- | --- | --- |
| Spectrum | Finite stack of layers, periodic in x and y | 1–64 layers; uniform films, built-in primitives, or imported/drawn two-material binary masks; constant or catalog/imported optical constants; s, p, or unpolarized illumination from either side | Total R, T, A=1−R−T and zero-order R/T |
| Single wavelength | Same finite stack | One vacuum wavelength and incidence direction | R/T/A, diffraction orders, Fourier-order and geometry-grid checks |
| Angle–wavelength map | Same finite stack scanned over incidence angle and vacuum wavelength at fixed azimuth | 3–201 points per axis; s, p, or unpolarized; R/T/A or zero-order R₀/T₀ | Color map with center-point Fourier check and skipped-cutoff reporting |
| Incident k-space map | Same finite stack scanned over transverse incident wavevector at one wavelength | Odd 5–201 point grid inside k∥/(nᵢk₀)=sinθ | R/T/A or R₀/T₀ over kx,ky with explicit polarization convention |
| Field map | Same finite stack | One patterned layer and depth within it | Horizontal x–y map of relative electric intensity and real Ex/Ey/Ez; refinement checks |
| Transfer matrix | Laterally uniform finite stack; independent scattering recursion | 1–8 uniform layers, absorbing or lossless, s/p/unpolarized, oblique incidence | Specular R/T/A spectrum and direct single-wavelength FMM comparison |
| Band structure | Infinite, z-invariant, lossless 2D crystal | Square, rectangular, or triangular/hexagonal Bravais lattice; one disk, square, or ring in a constant-index background | TE (Hz) and TM (Ez) frequencies on the standard high-symmetry path, Fourier-order comparison, and sampled complete reciprocal-cell gap screening |
| Planar waveguide | Separate three-medium, lossless, uniform dielectric core and two semi-infinite claddings | Core and cladding materials, core thickness, wavelength, TE/TM mode | Bound-mode effective index, propagation constant, approximate group index, transverse profile and confinement estimate |
| Measurement fit | Uploaded wavelength and R/T/A data compared with a uniform multilayer model | CSV data and one selected layer with bounded thickness | Overlaid curves, residuals, RMSE, and best-fit thickness |
| Cavity estimate | Ideal single-mode weak-coupling Purcell equation | Q, mode volume, wavelength, refractive index, detuning, and emitter linewidth | Ideal and detuning-adjusted enhancement estimates |
| Metasurface phase library | Infinite periodic cell sampled over one numeric geometry parameter | Coherent s/p at normal incidence; transmitted or reflected specular phase; lens radius and focal length | Phase/power library and LPA radial cell assignment; no finite-device propagation |
| Resonator metrics | Spectral/circuit relations for ring or knot measurements | Center, linewidth, group index, round-trip length, optional FSR and transmission depth | Loaded Q, FSR, finesse, lifetime, circulation estimate and two coupling branches |
| Observable-aware validation | One finite periodic stack at one operating wavelength | Total power and formulas using `Ro(m,n)` and `To(m,n)` | Adaptive Fourier, geometry-grid, per-order, energy, material-range and diffraction light-cone report with submitted-model fingerprint |
| Linked observable sweep | Same finite stack with one independent parameter and up to four affine links | Relations such as Py=Px or radius=0.39P; custom order formula; optional check at every point | Validated/not-converged/failed status per design and the best eligible point |
| Constrained geometry design | Same finite stack with one to five independent bounded parameters | Ordered named observables, weighted objectives, separate optical and geometric constraints | Explicit feasible/infeasible result, metric dashboard, active orders and automatic final Trust validation |
| Finite grating coupler | Finite, lossless, isotropic 2D scalar TE etched waveguide with an outgoing Gaussian target mode | Waveguide/grating geometry, finite period count, optional finite BOX and handle, target angle/waist/phase, binary or cell-averaged scalar raster, mesh, absorber and domain | Waveguide-launched target-mode overlap, spectrum/bandwidth, complex field/phase/relative Poynting maps, parameter screens, constrained and robust optimization, tolerance yield, analytic/uniform controls and mesh/absorber/padding/interface validation |

All lengths are in **micrometres**. Angles are in degrees. The frequency axis of a band diagram is **a/λ**, where `a` is the first primitive-vector length. Layers are always listed physically from top to bottom; the illumination control chooses which side is incident. A feature's dimensions are fractions of the unit-cell axes. Disk and ring radii are fractions of the period. A stripe extends across the complete unit cell in y and repeats in x, making a 1D grating. Square, rectangular, and oblique 60° triangular/hexagonal Bravais cells are available. “Triangular” and “hexagonal” here name the same Bravais lattice; the feature control selects the motif. Unpolarized R/T/A is the incoherent arithmetic mean of separate s and p runs; field maps require a chosen polarization.

For finite-slab RCWA, the illumination travels from the **incident medium through layer 1 and subsequent layers to the exit medium**. At normal incidence it points along +z. The polar angle θ is measured from that normal and azimuth φ from +x in the layer plane. To calculate illumination from the other face, reverse the layer order and swap the incident and exit refractive indices. This finite-slab model describes external plane-wave illumination; it does not automatically solve waveguide eigenmodes or launch light along a waveguide.

The **Planar waveguide modes** card is a separate 1D eigenmode calculation. Here the core fills 0 < z < thickness, with semi-infinite upper and lower claddings; light propagates along +x. It solves the TE electric or TM magnetic scalar slab dispersion condition, including the correct TM permittivity boundary factors. `n_eff = β/k₀` identifies the phase propagation constant. The transverse plot shows normalized |Eᵧ|² for TE or |Hᵧ|² for TM. The core fraction integrates the along-waveguide Poynting flux: |Eᵧ|² for TE, and |Hᵧ|²/ε for TM in these nonmagnetic media. It is not a coupling efficiency. The displayed group index is a central finite difference of `n_eff(λ)` and may be unavailable near cutoff; the interface reports the change when halving its wavelength step. This solver currently requires a uniform isotropic **lossless** core with a larger index than both claddings; it does not find lossy, leaky, laterally confined, or periodically patterned waveguide modes. Launching a guided mode into a patterned stack and measuring modal transmission is a separate calculation not yet provided.

The **waveguide-port illumination** card uses the full-vector 2D cross-section solver and projects a complex field on its solved modes. Analytic sources include elliptical Gaussian and super-Gaussian beams with independent x/y waists, displacement, in-plane ellipse rotation, polarization angle and relative phase, and port-plane tilt. A rectangular-grid CSV can instead supply `Ex` and `Ey`; adding `Hx` and `Hy` enables the forward/backward reciprocity power projection. The electric-only value is a normalized complex profile/polarization overlap. The directional value is a modal coupling efficiency only when the supplied E/H field is a physically consistent field on the same uniform waveguide port. Re-importing a solved mode returns unity forward overlap and zero backward overlap to numerical precision. The interface now compares source, best-mode and local overlap-density maps; screens waist, offset, tilt or polarization using one solved mode basis; reports the fraction captured by requested bound modes; and performs a half-mesh mode-tracked validation. This port calculation does not propagate through a finite grating, illuminate an apodized device, or include substrate leakage and transitions between the grating and output port. See [DEVICE_COUPLING_GUIDE.md](DEVICE_COUPLING_GUIDE.md) for equations and validation gates, and [ARCHITECTURE_CAPABILITY_ASSESSMENT.md](ARCHITECTURE_CAPABILITY_ASSESSMENT.md) for the audited architecture, capability gaps, milestones, and acceptance tests.

The separate **Finite grating coupler** workspace performs a 2D scalar TE finite-difference frequency-domain solve for a finite uniform grating connected to a uniform waveguide. It launches a normalized guided mode, projects upward radiation on a selected outgoing Gaussian target mode, and reports that genuine out-coupling calculation. It does not substitute this number for an independently solved incoming-beam calculation. The shared geometry supports either the legacy semi-infinite oxide or a finite BOX and silicon handle. A legacy binary raster and a deterministic cell-averaged scalar epsilon raster are selectable; the latter is not full-vector tensor smoothing. The workspace includes spectra and sampled bandwidth, complex field/phase/material/relative-Poynting views, physical parameter screens, bounded constrained optimization, fixed-sample robust optimization, fabrication tolerance/yield, project persistence, an analytic slab plus uniform-waveguide baseline, and independent mesh/absorber/domain/interface-raster validation. The closed budget includes upward radiation, substrate leakage, residual guided power, back-reflection, and numerical/absorber residual. Incoming Gaussian equivalent-current excitation, bidirectional reciprocity error, per-tooth apodization, finite lateral width and full-vector 3D remain outside this solver.

The finite-device matrix is assembled directly from five sparse diagonals rather
than Python per-entry lists. The default safety limits are 300,000 cells locally
and 80,000 cells on the shared Render service; administrators can set
`FINITE_GRID_LIMIT_LOCAL` and `FINITE_GRID_LIMIT_PUBLIC`. The interface estimates
grid dimensions, base sparse-array memory, and a safe mesh before a run. Meshes
down to 0.005 µm are accepted when the selected physical domain fits the cell
budget. Sparse LU factorization can require several times the displayed base
storage, so passing preflight is not a runtime or publication guarantee.

Imported optical-constant CSV tables are validated on the server and retained in a namespaced browser library. Saved Workbench projects embed the source table and provenance so an online session can restore it after an ephemeral service restart. The Render container keeps only a temporary working copy; the browser/project copy is the reproducible record. Do not include confidential specimen data in a shared public deployment.

The **Usage statistics** workspace reports approximate anonymous browser count, sessions, page views, completed/failed calculations, daily activity, and popular calculation types. A browser-generated random identifier is stored locally and only its shortened SHA-256 hash is retained by the server. The counter does not collect IP addresses, user agents, identities, uploaded files, solver inputs, or results. Local totals use `.usage_stats.json`. The supplied free Render configuration writes to `/tmp/fmm-usage-stats.json`, so its “since” timestamp can reset after a rebuild, restart, or host migration. For lifetime production totals, mount durable storage and set `USAGE_STATS_PATH` to that path.

The interface automatically keeps settings and results side by side on desktops, laptops, and landscape tablets, then stacks them in portrait and on narrow screens. Scientific canvases retain a readable minimum size inside horizontal plot frames, while forms, metrics, tables, navigation, and run controls reflow independently. The **Workspace layout** selector in the run bar lets a user override the automatic choice with Split or Stacked view; the preference is stored in that browser.

The **upper/lower coupled-branch** card accepts the first two tracked resonances or a three-column CSV and fits their photon energies to a Hermitian 2×2 model with one linear bare photonic branch and one constant bare matter energy. It reports `g`, minimum splitting `2g`, residual error, and upper/lower photonic and matter Hopfield fractions. Optional bare linewidths add `4g²/(γcγx)` and splitting-to-mean-linewidth indicators. These are model-dependent composition and spectral metrics. They are not excitation, transfer, or collection efficiencies, and the fit does not replace complex-pole or quasinormal-mode analysis.

The **Unpatterned slab-mode phase matching** assistant links this bound-mode model to a periodic stack through `β ≈ |k_parallel + m b1 + n b2|`. A selected uniform layer is used exactly; a patterned layer is replaced by the arithmetic unit-cell mean of ε and this homogenization is reported. The assistant evaluates reciprocal vectors for square, rectangular, and oblique cells and ranks integer `(m,n)` orders by relative momentum mismatch. This establishes momentum compatibility only. Patterning can shift the mode and controls overlap, radiation loss, linewidth, and coupling strength, so the actual resonance must be verified with FMM spectra, fields, angular or period dispersion, and convergence.

The gold table is Johnson and Christy's measured bulk `n,k`, interpolated separately without extrapolation. The supported range is 0.1879–1.9370 µm. Fused silica uses Malitson's Sellmeier formula over 0.21–6.7 µm. N-BK7 optical glass uses the SCHOTT Sellmeier formula over 0.3–2.5 µm. Calcium fluoride uses Malitson's Sellmeier formula over 0.23–9.7 µm. Crystalline silicon uses the Green 2008 tabulated `n,k` at 300 K within its tabulated wavelength range. The library also contains ordinary-ray dispersion for rutile TiO₂ (DeVore, 0.43–1.53 µm), synthetic sapphire α-Al₂O₃ (Malitson–Dodge, 0.20–5.0 µm), and MgF₂ (Dodge, 0.20–7.0 µm). Formula models return real n and do not represent absorption near transparency edges. Constant-index dielectrics are idealizations, not a measured dispersion model.

The Materials workspace includes a separate constitutive calculator for a rotated uniaxial permittivity tensor, scalar relative permeability, thermo-optic and Kerr index shifts, and small-signal gain. It solves the exact homogeneous plane-wave Maxwell eigenproblem and reports the two bulk indices and polarizations. This is material preprocessing and validation: tensor ε/μ, heat diffusion, nonlinear self-consistency, and gain saturation are not yet coupled to the layered FMM, band, or waveguide matrices.

## Validation and how to interpret the badges

The automated tests check measured-material reference values and range limits, analytic Fresnel reflectance at normal and oblique incidence for both polarizations, complex diffraction-order fields, linear-polarization Stokes limits, coherent far-field k-space maps, slab/grating phase matching, an independent Fabry–Pérot formula for a uniform N-BK7 film, power balance and layer-resolved absorption for dielectric and absorbing structures, square/rectangular/hexagonal band calculations, complete reciprocal-cell screening, the analytic folded bands of a uniform 2D medium, measurement fitting, Bayesian diagnostics, robust optimization, vector core masks, custom diffraction observables, linked-parameter sweeps, immutable validation fingerprints, finite BOX/material rasterization, scalar interface averaging, complex finite-device fields, the Q/V cavity expression, the Ag/TDBC–PVA two-branch strong-coupling benchmark, and a published MPB square-rod benchmark. The guided-mode tests compare both polarizations against independent symmetric half-slab dispersion equations and check mode bounds, cutoff, fields, and figures. In the MPB case (rod ε=12, r/a=0.2, k=(0.3,0.3)), this plane-wave code gives first TE frequency **0.37555** at Fourier order 7, compared with **0.372604** in the MPB tutorial. The difference is 0.00295 in normalized frequency (0.79%). That is a useful independent check, **not** a universal accuracy bound.

Every quantitative plot has a **Raw data + metadata** action. Line plots export the sampled series; two-dimensional maps export both coordinate arrays and the unsmoothed calculated matrix. The JSON also records the current model, plot identity, palette, smoothing selection, timestamp, and a reminder that display interpolation does not change the numerical samples.

The single-wavelength convergence gate follows total R/T/A and every retained propagating diffraction order between the final two refinements. The dedicated **Validation report and diffraction light cones** card also follows a user-defined observable such as `To(1,0)+To(-1,0)`, doubles the geometry grid, checks energy and material range, classifies retained orders as propagating, evanescent, or grazing, and fingerprints the submitted model. It offers explicit **Exploratory** (`1e-2`), **Research** (`1e-3`, default), **Publication** (`2e-4`), and **Custom** acceptance profiles for dimensionless power and diffraction-order observables. A spectrum compares Fourier orders point by point, but does **not** double the geometry grid at every wavelength; select important wavelengths for the full report. A field map compares its intensity pattern across Fourier and grid refinements using a relative RMS threshold of 0.10. Band diagrams compare each displayed band between adjacent Fourier orders with a 0.01 normalized-frequency threshold.

These thresholds are numerical gates, not proof of experimental accuracy or publication readiness. The Publication profile is deliberately stricter, but it does not replace quantity-specific checks: resonance center and linewidth require sampling and fit-window stability; fields require relative-map and hotspot stability; modes require effective-index and overlap stability; and tolerance studies require stable statistics. Near a resonance, at a Rayleigh cutoff, or at a sharp metal boundary, convergence may be slow. Results that fail are shown for diagnosis but figure export is disabled. The legacy gold-rectangle preset near 0.9 µm **fails** Fourier convergence and must not be used as a quantitative result. The solver rejects exact grazing-order cutoffs where its matrices become singular.

The R/T/A values include all propagating orders retained by the solver. Global absorptance is the residual `1−R−T`. The vertical-field workspace computes each layer's absorption from the decrease in Fourier-domain unit-cell-averaged normal Poynting flux and checks its sum against global absorptance. It independently integrates `normalization × ω Im(ε)|E|²` over the complete sampled unit cell and layer thickness and reports both values. Their difference is a spatial-integration convergence diagnostic. Horizontal and vertical field maps are relative to the solver's unit incident-wave convention, not calibrated experimental intensity. The weak-loss Brillouin energy estimate uses `¼{[ε′−λ dε′/dλ]|E|²+|H|²}` and is marked unsuitable when any selected material has `k/n > 0.01` or a nonpositive derivative coefficient. The original nondispersive proxy remains available for comparison.

Single-wavelength coherent s or p results include the complex Cartesian E and H coefficients of every propagating reflected and transmitted diffraction order. The interface shows the dominant tangential electric component, magnitude, and phase. It also projects each outgoing channel onto its local p/s basis and reports complex Jones coefficients, normalized Stokes parameters, polarization orientation, and ellipticity. The convention is `S3 = −2 Im(Ep Es*)`; exported JSON retains all components. Phases use the incident-wave reference and depend on the selected port/reference-plane convention. Unpolarized light is an incoherent s/p average and therefore has no single coherent order phase or Jones vector.

The Jones and Stokes k-space workspace repeats that coherent channel calculation over incident `kx,ky`. It can map channel power, normalized complex `Ep,Es`, normalized Stokes parameters, orientation, and ellipticity for a selected reflected or transmitted diffraction order. Values below a user-selected power threshold are masked because normalized polarization is unstable as `S0→0`. Every pixel is a driven scattering result and includes any direct background. It is not the isolated radiation coefficient of a leaky eigenmode. A BIC charge requires the winding of the isolated mode radiation polarization around a closed momentum-space loop, together with mode tracking and convergence; the present workspace intentionally does not assign that charge.
The field viewer also allows real Ex, Ey, and Ez components. Their signed patterns depend on the chosen incident phase reference, so use |E|² for phase-independent enhancement comparisons. The field figure export follows the selected quantity and labels its color scale.

In the slab solver, the Fourier input is a requested total number of harmonics. The solver chooses and reports the actual retained count, which need not equal the request; the input itself need not be odd. In the band solver, the input `N` is a radius and the basis contains orders `−N…+N`, or `2N+1` along each reciprocal axis. The single-wavelength result plots R/T/A against actual retained harmonics and also shows the largest order and grid changes against a dashed acceptance limit. Passing this numerical screen does not replace an independent comparison for the specific sample.

## If the app gives an error

Read the message above the plot first. Material range errors mean the selected wavelength falls outside the cited optical-constant data; choose an in-range wavelength or a justified custom index. A grazing-cutoff message means a diffraction order is exactly at threshold; move the wavelength or angle slightly. Invalid geometry messages identify a fraction, radius, layer count, grid size, or index to correct. A failed convergence check is a calculated but unresolved result: inspect the convergence chart, raise Fourier harmonics and grid resolution within limits, and avoid quoting the unstable value. For an unexpected server error, inspect `workbench.log` in this folder for a traceback, run the unit tests from the Start section, and keep the input settings and error message for reproduction. The browser's developer console can reveal JavaScript errors if a control does not respond.

## Relation to the MATLAB files

- The legacy MATLAB files remain untouched. They are not used as trusted numerical references because several geometry and unit choices are ambiguous. The `PWEM_imp.m` square test compares a length to a squared radius (line 45), and the ring/triangle branches use separate discretization choices. These should be corrected before direct cross-code numerical comparison.

## Reproducibility and publication

Export **JSON** with parameters and results and **CSV** for validated spectra. Export **SVG** for editable vector figures or **PNG** at 300 dpi. Include the optical-constant source, all layer parameters, incidence angle/polarization, Fourier order, spatial grid, convergence changes, and package versions in a methods section. Keep a record of any data-processing or fitting steps performed outside this workbench.

For a publishable conclusion, repeat the calculation with higher orders and grid size, compare against an independent solver or experiment for the specific geometry, and include material-property uncertainty. A slab spectrum peak cannot by itself be identified as an infinite-crystal band edge; the two calculations have different boundary conditions.

## Current research limits

This is a validated **preview**, not a full Lumerical replacement. Gold patches close to the original 2018 scan have not converged at the installed solver's practical order budgets. Near-field maps, band edges, resonant features, and any new material or geometry need case-specific convergence and external comparison before they support a research claim. Multi-parameter fitting provides local covariance, correlation, conditional confidence intervals, reserved-wavelength validation, and optional residual bootstrap. The Bayesian workspace adds bounded multi-chain posterior sampling under an explicit Gaussian or AR(1) residual likelihood; its intervals remain conditional on the chosen optical model, priors, bounds, and noise model. Pause and resume operate between completed solves rather than resuming a matrix factorization in progress. Driven k-space Jones/Stokes maps and a stability-checked complex-sideband resonance decomposition are available, but polarization-vortex winding and topological charge still require an isolated patterned-mode pole. Band scalar eigenfields and a frozen-index normal-incidence complex-pole solver for uniform multilayers are available. A dyadic Green-function solver gives planar electric-dipole LDOS and rigorous upper-medium objective-cone collection for uniform multilayers, including orientation and numerical refinement. It does not provide a beta factor into a named mode. Patterned-source LDOS, patterned RCWA poles, normalized quasinormal fields, and self-consistent thermal/nonlinear/gain/tensor stack simulations remain future solver subsystems. A full-vector finite-difference mode workspace is available for rectangular, elliptical, and trapezoidal isotropic dielectric cores and returns all six complex field components; mesh and boundary convergence remain mandatory.





## Resonance and angular workflows

- Spectrum plots show R, T, A, and the energy-accounting sum R+T+A. Hover to inspect sampled values; click a wavelength to send it to Single wavelength and Field map.
- Two-dimensional maps offer sampled-cell, linear, and high-quality smooth rendering after a solve. Interpolation is visual only; hover reports the nearest solved sample.
- Signed angle maps use negative theta as the reversed in-plane wavevector (phi + 180 degrees), enabling symmetry comparisons about normal incidence.
- Adaptive resonance analysis refines a wavelength interval and fits a Fano profile, with a Lorentzian fallback for symmetric features. Reported linewidth, Q, and covariance errors remain far-field fit estimates. They do not prove an ideal BIC.
- The adaptive workspace retains its single-feature workflow and now also offers a multi-feature workflow. The latter performs a global candidate scan, candidate-wise refinement, joint shared-background Lorentzian/Fano fitting, BIC model comparison, covariance and overlap warnings, and field-signature-assisted branch assignment. These remain phenomenological far-field fits rather than complex-frequency poles or QNMs.
- Geometry primitives include 1D ridges and slots, rectangular and circular pillars or holes, ellipses, disks, rings, and uniform films. The stack supports up to 64 finite layers.

## Visualization conventions

Quantitative line plots use labeled axes, units, legends, sampled-point markers, and hover readouts. Two-dimensional maps use numeric colorbars and hover readouts of the nearest calculated sample. Horizontal field plots overlay the selected feature boundary; vertical fields and resonance-field comparisons overlay layer interfaces; band eigenfields overlay material boundaries; planar mode profiles overlay physical layer boundaries. The global display selector can smooth raster presentation, but exported interpretation must treat smoothing as visual interpolation rather than additional simulation data.


## Expanded optical materials

The library now includes Rakic Lorentz–Drude Ag, Al, and Cu over 0.1–6 eV; measured PMMA, polycarbonate, polystyrene, and Zeonex E48R values over 0.4368–1.052 µm; and a measured-film SiN Sellmeier fit over the explicitly limited interface range. These models are process dependent. Thin metal films, deposited SiN, and commercial polymers can differ from the cited specimens, so sample-specific ellipsometry should be imported for quantitative device fitting. Field JSON now includes real E and H components and time-averaged Poynting components used by the normalized arrow overlays.

## Closed-loop polarization winding

The scattering workspace tracks a fitted resonance around a closed momentum-space loop, subtracts a symmetric complex sideband background in fixed laboratory Cartesian coordinates, unwraps the headless polarization-axis angle, and tests stability against loop radius, sideband selection, ellipticity, residual amplitude, branch continuity, and Fourier convergence. Sideband subtraction approximates an isolated pole residue, so rigorous ideal-BIC proof still requires the future patterned outgoing-mode solver.


## General constrained geometry optimization

The Sweeps and design workspace supports one to five bounded model parameters, one to eight weighted optical objectives, optional linear geometry constraints, and up to twelve optical constraints. Reusable observables are ordered named expressions built from `R`, `T`, `A`, `R0`, `T0`, `Ro(m,n)` and `To(m,n)`; a later definition may use an earlier name. Objectives and constraints reference the same definitions, so a two-order splitter can maximize `eta2` while independently requiring `eta2 ≥ 0.70`, `balance ≤ 0.02`, and limited unwanted transmitted power. The optimizer reports feasibility separately from score, returns a design dashboard and evaluation history, and automatically runs the full observable-aware Trust validation at every objective or constraint wavelength. It uses seeded differential evolution with optional local polishing and remains a low-dimensional shape and parameter optimizer rather than a pixel-level adjoint topology optimizer. Repeat stochastic searches with multiple seeds and evaluate tolerance before accepting a design.
