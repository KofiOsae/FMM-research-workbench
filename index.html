The section starts inside the top semi-infinite medium, crosses every finite layer, and ends inside the bottom semi-infinite medium. The physical top interface is z=0; negative z is the top medium. For an oblique lattice the horizontal coordinate follows primitive vector a₁ or a₂.

Bands describe an infinite, lossless 2D crystal, with no finite slab thickness. Complex-index materials are excluded from this Hermitian calculation.

Square and rectangular lattices use Γ–X–M–Γ. The hexagonal choice uses a triangular primitive cell and Γ–M–K–Γ. “Triangular lattice” and “hexagonal lattice” commonly name the same 2D Bravais lattice; the feature shape is selected separately.

    Quality and interpretation

    A power balance is useful but does not prove Fourier convergence. Run the single-wavelength check where you intend to quote a numerical value.

    How to read this result

    R and T are fractions of incident power, summed over all propagating diffraction orders. A = 1 − R − T. A spectral feature is a candidate for further analysis, not by itself proof of a resonance or band gap.
    Quick tutorial
    1. Choose incident and exit media, periods, and layers. Each layer thickness is along z. For a 1D grating, select Stripe and set its width as a fraction of the x period.
    2. Use Spectrum to locate features in wavelength. R and T include all propagating diffraction orders; A = 1 − R − T.
    3. Select a wavelength and run Single wavelength. The workbench compares several Fourier budgets. Quote results only when this check passes and the geometry is physically justified.
    4. Use Field map to view relative electric intensity inside a patterned layer. A sharp local peak needs extra spatial and Fourier convergence checks. Use s or p illumination for fields.
    5. Use Band structure for a separate infinite, lossless 2D crystal. The vertical axis is normalized frequency a/λ. A slab spectrum peak is not automatically a bulk band.
    6. Export SVG/PNG for figures and JSON/CSV for reproducibility. Include material source, software versions, geometry, grid, and convergence in publication methods.
    If a calculation gives an error
    1. Read the message above the plot. Check wavelength against the selected material data range, layer dimensions, and the allowed grid and order settings.
    2. If it says an order is at grazing cutoff, change the wavelength or incidence angle slightly and rerun.
    3. For a failed convergence check, try a simpler geometry, higher Fourier budget, and finer grid. Do not publish the failed values.
    4. If the server reports an unexpected error, inspect workbench.log in the application folder. Run .venv\Scripts\python.exe -m unittest -v from a terminal and keep the input settings for a reproducible report.
